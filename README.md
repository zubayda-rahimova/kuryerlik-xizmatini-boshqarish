# Kuryerlik xizmatini boshqarish tizimi

## Loyiha haqida
Ushbu o‘quv loyihasi kuryerlik xizmatidagi buyurtmalar, kuryerlar, jo‘natmalar,
manzillar va yetkazib berish holatlarini boshqarish uchun mo‘ljallangan.

## Maqsad
Buyurtmalarni ro‘yxatga olish, kuryerga biriktirish va yetkazib berish holatini
kuzatish jarayonlarini yagona tizimda tashkil etish.

## Asosiy funksiyalar
- Buyurtmalarni yaratish, ko‘rish va yangilash
- Kuryerlar ma’lumotlarini boshqarish
- Jo‘natma va yetkazib berish manzillarini saqlash
- Buyurtmani kuryerga biriktirish
- Yetkazib berish holatini yangilash
- Buyurtmalarni qidirish va oddiy hisobotlarni ko‘rish

## Foydalanuvchi rollari
- Administrator
- Dispetcher/operator
- Kuryer
- Mijoz (buyurtma holatini kuzatish)

## Loyiha holati
Rejalashtirish bosqichi. Funksiyalar laboratoriya ishlari davomida bosqichma-bosqich
aniqlanadi, ishlab chiqiladi va sinovdan o‘tkaziladi.
